# CyberCode v1.1.24

## Fast Judgment And Browser Tasks

- Adds an optional fast judgment layer with Jev's official API and a local Reflex 4B endpoint. Reflex is selected for new configurations, but fast judgment remains off until explicitly enabled.
- Saves separate provider settings, keeps API keys out of settings responses, and links directly to the official TypeSafe API key page.
- Uses bounded, batched decisions to shorten eligible older tool results while preserving recent context and the original conversation history. Missing credentials, timeouts, and unavailable services fall back to the existing flow.
- Adds an independently enabled browser task accelerator. The main model can delegate short tasks to the configured judgment service while retaining existing browser sessions, tool permissions, and hooks.
- Returns uncertain or unsupported browser actions to the main model for verification and continuation. Browser acceleration is off by default.
- Local Reflex requires a separately installed inference server and suitable hardware; Python and model weights are not included. Real Jev latency and Reflex 4B inference speed have not been benchmarked for this release.

## Desktop Improvements

- Indents tasks further beneath their projects in the sidebar.
- Adds a pin action in the model picker to set the default model or route for new conversations.
- Smooths thinking and tool activity expansion while respecting reduced-motion preferences.
- Generates conversation titles through the selected provider or route, preserves manual names, and adds a setting to disable automatic titles.
- Starts update checks with the app, rechecks on return after inactivity, and improves manual update feedback and download timeouts.

## Platforms And Downloads

- macOS Apple Silicon: DMG and application ZIP.
- macOS Intel: DMG and application ZIP.
- Windows x64: NSIS installer, installer ZIP, and portable ZIP.
- Linux x64: DEB, DEB ZIP, and portable AppImage.
- Signed updater archives and update manifests are included.

The release workflow runs judgment, browser-task, settings, external-link, and sidecar checks on all four native runners. Publication requires all builds, ZIP integrity checks, packaged runtime checks, and required release assets to succeed.

## Release Reliability

- Synchronizes Bun and npm lockfiles so clean CI installations succeed.
- Enforces frozen lockfile installation in all desktop release builds.
- Replaces the cancelled v1.1.23 build; v1.1.23 was not published as a GitHub Release.
